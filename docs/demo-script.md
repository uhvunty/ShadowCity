# 4-minute hackathon demo script

1. **Problem (30 sec):** Neighbourhood infrastructure is interconnected, but it is difficult to understand cascading effects of disruptions.
2. **Show the twin (30 sec):** Open the demo neighbourhood and point out roads, buildings, hospitals, school and drainage markers.
3. **Run flood scenario (60 sec):** Select Flood, set rainfall to 100 and drainage blockage to 70, then run the simulation.
4. **Explain results (45 sec):** Show relative susceptibility zones, affected roads, building exposure and facility accessibility. Emphasise that the current model is an illustrative susceptibility score.
5. **Compare scenarios (45 sec):** Run a second scenario with lower blockage and compare affected counts.
6. **Show road closure (30 sec):** Close a road and demonstrate route/connectivity changes.
7. **Close (20 sec):** Explain the path to a validated, data-connected neighbourhood digital twin.
